# Social icon attribution

Instagram, Facebook F and WhatsApp SVG brand marks are from Font Awesome Free 6.7.2 by Fonticons, Inc. SVG comments retain the upstream attribution. The SVG fill is set to white for the site contact buttons; brand paths are unchanged.

- Source: https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs/brands
- Icon license: Creative Commons Attribution 4.0 International (https://creativecommons.org/licenses/by/4.0/)
- License details: https://fontawesome.com/license/free

Icons are served locally from `public/images/social/`; no external runtime requests or icon-library JavaScript are required.
